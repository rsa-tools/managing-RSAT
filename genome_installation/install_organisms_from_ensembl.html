Installing genomes from Ensembl

Bruno Contreras Moreira

2026-10-02

The Ensembl browser (https://www.ensembl.org) contains a large number of annotated and curated genome sequences. Originally it contained mostly genomes of Vertebrate organisms, but since the release of the new Web browser in the summer of 2026 it now contains genome data for all organisms, including bacteria, fungi, plants and metazoa, which used to be under Ensembl Genomes.

The program install-organism-ensembl manages all the required steps to download and install genomes (sequences, annotation, variations if available) from Ensembl. Files are retrieved from https://ftp.ebi.ac.uk/pub/ensemblorganisms and the metadata parsed from the species.json, which is copied locally at $RSAT/downloads for efficiency.

1 Examples

install-organism-ensembl -task available lists the genomes currently available at Ensembl. The first few lines of the output should be similar to these:

Abax_parallelepipedus.GCA_964197645.1.2025_03.ensembl   [icAbaPara2.1, ]
Abiotrophia_sp_hmsc24b09.GCA_001815865.1.2026_06.prokka [ASM181586v1, HMSC24B09]
Abramis_brama.GCA_022829085.1.2024_01.ensembl   [ASM2282908v1, Europe]

The first column shows the genomeID, which is a combination of the organism name, the assembly version and the annotation. The second column shows the assembly name and the strain or variety (if any).

In the terminal you can manipulate the output with standard Unix commands (grep, cut, perl, …) to select the organisms of your choice or save them in a file.

install-organism-ensembl -task default can be used to download and install in your local RSAT instance genomes of your choice. Selected genomeIDs can be indicated one by one as parameters:

install-organism-ensembl -task default \
  -org Abax_parallelepipedus.GCA_964197645.1.2025_03.ensembl

install-organism-ensembl -task default \
  -org Abax_parallelepipedus.GCA_964197645.1.2025_03.ensembl \
  -org Abramis_brama.GCA_022829085.1.2024_01.ensembl

Or they can be listed in a file, one genomeID per line, and the option -org_file can be used to indicate the file name:

install-organism-ensembl -task default -org_file my_genomes.txt

Note that the task default actually comprises the following tasks: download, parse, install, which can also be carried separately:

install-organism-ensembl -task download \
  -org Abax_parallelepipedus.GCA_964197645.1.2025_03.ensembl
install-organism-ensembl -task parse \
  -org Abax_parallelepipedus.GCA_964197645.1.2025_03.ensembl
install-organism-ensembl -task install \
  -org Abax_parallelepipedus.GCA_964197645.1.2025_03.ensembl

Check all the options of the program with:

install-organism-ensembl -h

2 Local checks

Upon completion of these tasks, all the genome files will be stored at the corresponding genome directories:

$RSAT/data/genomes/genomeID

and the organisms should be listed in the output of:

supported-organism

3 Limitations

install-organism-ensembl might change as the new Ensembl platform develops.

install-organism-ensembl -task install does not yet install variations.
